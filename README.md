## 📱 Responsive

El diseño fue preparado para funcionar en:

- móviles pequeños;
- tablets;
- escritorio;
- pantallas anchas.

Incluye menú móvil, navegación por teclado, estados de foco y soporte para `prefers-reduced-motion`.
